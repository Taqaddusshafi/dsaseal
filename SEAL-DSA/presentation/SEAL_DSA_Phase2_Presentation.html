Project Overview

Teaching a language model to become its own DSA tutor

🎯

Problem Statement

Large Language Models (LLMs) provide generic answers to DSA questions. They lack structured, curriculum-aligned teaching ability for progressive skill building.

💡

Proposed Solution — SEAL

A self-evolving loop where the model generates questions, answers them, self-evaluates, and updates its own weights — creating an autonomous DSA tutor.

🔧

Technical Approach

  • Qwen2.5-1.5B-Instruct as base model
  • 4-bit QLoRA for memory efficiency
  • EWC to prevent catastrophic forgetting
  • IRT-based curriculum scheduling
📊

Key Contributions

  • Novel self-teaching training loop
  • IRT competence-based curriculum
  • Automated forgetting detection
  • Runs on free Google Colab (T4 GPU)

Key Technical Fixes

The three most critical issues that blocked all LoRA learning

🔴 Before: AMP + 4-bit Quantization Conflict

# GradScaler + NF4 quantization = NaN
scaler = torch.cuda.amp.GradScaler()
with autocast(dtype=float16):
  loss = model(labels=labels).loss
scaler.scale(loss).backward() # 💥 NaN

🟢 After: Disabled AMP for Quantized Models

# 4-bit models manage their own dtype
if self.quantization_enabled:
  self.use_amp = False

loss = model(labels=labels).loss
loss.backward() # ✅ Clean gradients

🔴 Before: Raw Text Prompts

# Prompt format ≠ model's pretraining
prompt = "Question: ... Answer:"
# Model never saw this format → confused

🟢 After: Chat Template Alignment

# Matches Qwen2.5-Instruct format
msgs = [{"role": "user", ...}]
prompt = tokenizer.apply_chat_template(
  msgs, add_generation_prompt=True
) # ✅ Train = Inference format

🔴 Before: Wrong Label Masking

# Encoded full text, guessed split point
full = tokenizer(question + answer)
split = len(question) # ← character count!
# Token boundary off by 5-10 tokens

🟢 After: Separate Tokenization

# Tokenize input and output separately
input_ids = tokenizer(question).input_ids
answer_ids = tokenizer(answer).input_ids
labels[:len(input_ids)] = -100
# ✅ Exact token boundary

Novel Contributions

Research innovations in the SEAL-DSA framework

🔄

Self-Teaching Loop

Unlike traditional fine-tuning which requires external datasets, SEAL generates its own training data through a closed-loop process: Question Generation → Self-Answering → Self-Evaluation → Weight Update. The model teaches itself by reinforcing correct answers and discarding incorrect ones.

📈

IRT-Based Competence Estimation

Applies Item Response Theory (1PL model) from psychometrics to estimate the model's "ability" (θ) on each topic. Topics in the Zone of Proximal Development (θ ∈ [-1, 1]) are prioritized — the model trains on what it can learn most from.

P(correct|θ,b) = 1 / (1 + exp(-(θ-b)))

🛡️

Dynamic EWC with Forgetting Detection

Combines EWC regularization with real-time forgetting detection. The regularization strength (λ) adapts automatically based on measured forgetting rates across previously learned topics — preventing catastrophic forgetting while allowing new learning.
